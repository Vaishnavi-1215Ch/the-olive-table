# The Olive Table

A responsive restaurant website created as the fourth Fiverr portfolio demonstration. The Olive Table, its team, address, menu, reviews, and contact details are fictional. The reservation form is a front-end demo and does not send data or create a booking.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Included

- Editorial, food-first landing page with responsive navigation
- Restaurant story, featured dishes, tabbed menu, chef recommendation, gallery, and fictional customer reviews
- Reservation demo with required-field validation and an on-page confirmation
- Location details, sample opening hours, contact links, social links, and a responsive illustrated map
- Smooth anchor navigation, accessible reduced-motion support, and subtle scroll reveals

Food photography is loaded from Unsplash and the typefaces from Google Fonts, so those assets require an internet connection.
